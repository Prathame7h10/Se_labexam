# Se_labexam
# Online Food Ordering System – Place Order Testing

## Files
| File | Description |
|---|---|
| `place_order.py` | Main system (classes + logic) |
| `test_blackbox.py` | 15 Black Box test cases (ECP + BVA) |
| `test_whitebox.py` | 15 White Box test cases (Statement + Branch Coverage) |

## Requirements
- Python 3.10+
- No external libraries needed

## How to Run

```bash
# 1. Keep all 3 files in the same folder

# 2. Run Black Box tests
python test_blackbox.py

# 3. Run White Box tests
python test_whitebox.py
```

## Expected Output
```
TOTAL: 15  |  PASS: 15  |  FAIL: 0
```
Both suites should show 15/15 PASS.
